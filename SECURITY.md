# Security policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues. Use GitHub's **Report a vulnerability** form in the repository's Security tab to send a private report.

Include the affected version, impact, reproduction steps, and any suggested mitigation. Remove certificates, private keys, device IP addresses, pairing codes, and other sensitive data from logs and attachments.

Maintainers will acknowledge the report when possible, investigate it privately, and coordinate disclosure after a fix is available. Only the latest released version and the current default branch receive security fixes.

---

# Politique de sécurité

Ne publiez pas une vulnérabilité dans une issue publique. Utilisez le formulaire **Report a vulnerability** de l’onglet Security du dépôt afin de transmettre le signalement de manière privée.

Indiquez la version concernée, l’impact et les étapes de reproduction. Retirez des journaux et pièces jointes les certificats, clés privées, adresses IP, codes d’appairage et toute autre donnée sensible. Seules la dernière version publiée et la branche principale courante reçoivent des correctifs de sécurité.
