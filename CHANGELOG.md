## 0.2.0

### Added

- Native C++20 Android TV Remote v2 client library.
- Pairing, certificate generation, remote control, text input, App Links, and voice input.
- Static and shared CMake builds with unit and simulated TLS integration tests.
- Cross-compilation helpers for Linux, Windows, and macOS targets.
